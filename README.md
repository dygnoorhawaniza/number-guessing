# 🎯 Number Guessing Game

A simple number guessing game built with **JavaScript** as a beginner programming project.

The goal is simple: guess the randomly generated number and see how many attempts it takes!

### 🕹️ How It Works

1. The program generates a random number.
2. Enter your guess.
3. The program tells you whether your guess is **too high** or **too low**.
4. Keep guessing until you get the correct number. 🎉

### 🛠️ Built With

* JavaScript
* Node.js

### ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/dygnoorhawaniza/number-guessing.git
```

Navigate to the project:

```bash
cd number-guessing
```

Install dependencies:

```bash
npm install
```

Run the game:

```bash
node assignment9.js
```
